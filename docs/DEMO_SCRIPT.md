# Сценарій демо (2–5 хв)

1. Запустити `php artisan serve` і `npm run dev`, відкрити `http://localhost:8000`.
2. Показати prefilled demo login і виконати вхід. Звернути увагу, що баланс завантажився з `/api/me`, а токен збережено в браузері.
3. Ввести `WELCOME10`, натиснути «Застосувати»: показати success message, бонус ₴10.00 і збільшений баланс.
4. Повторити `WELCOME10`: показати помилку «вже був використаний» і рядок `Відхилено` в історії.
5. Ввести `EXPIRED1`: показати окрему причину «термін дії минув».
6. У рядку успішного claim натиснути «Скасувати», підтвердити дію: показати оновлений баланс і статус `Скасовано`.
7. За бажанням натиснути revoke ще раз через DevTools/API або повторно відкрити запит: показати 409 без повторного списання.
8. Показати фільтр `Застосовані`/`Відхилені` та, якщо є достатньо записів, пагінацію.

Для послідовності скріншотів достатньо кадрів після кроків 2, 3, 4, 5 і 6.
